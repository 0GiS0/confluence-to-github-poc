## Notes on the export process

- Idempotency: the seed script converges to the same content on re-runs, but Confluence normalises the stored XHTML, so most pages get a new version each run. The content does not change. Expect version numbers to increase.
- The converter config (`config/cme-settings.json`) sets `page_path` and `page_path_if_parent` so every parent page becomes a `README.md`. Templates start with `{space_name}/`, which avoids an absolute path for the root page.
- The export is a full re-export (`skip_unchanged` is false), with `cleanup_stale` enabled.
- Credentials are read from `~/.config/confluence-poc/.env` and are never written to the repository. The generated converter config lives in `.work/` (gitignored, mode 600).
