# Dev Environment Setup

Install the toolchain: Python 3.12, Node 22 and Docker Desktop.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

> [!IMPORTANT]
> Use the company VPN when pulling internal packages.
